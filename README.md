# Baton Rouge Plumbing — Modern Website

A modern, mobile-responsive website for Baton Rouge Plumbing LLC, a family-owned plumbing company in Baton Rouge, LA serving the community since 1986.

**Built by Icebourg Design**

## Features
- Mobile-first responsive design
- Dark theme with glassmorphism aesthetics
- SEO-optimized with Schema.org LocalBusiness markup
- Service showcase (6 service categories)
- Contact form with service selector
- Emergency contact section
- Open Graph support

## Tech
- Single-file HTML (no build tools needed)
- CSS custom properties for theming
- Vanilla JS for mobile nav toggle
- JSON-LD structured data for local SEO

## Deployment
Open `baton-rouge-plumbing-site.html` in any browser. Ready for any static hosting (Vercel, Netlify, Cloudflare Pages, Google Cloud Run).
